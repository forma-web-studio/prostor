# ПРОСТОР — студия интерьерной архитектуры

Вымышленная студия для владельцев квартир и загородных домов, которым нужен спокойный, функциональный интерьер. Позиционирование: естественные материалы, работа со светом, внимание к повседневной жизни. Проект показывает умение создавать редакционную вёрстку и продавать визуальную услугу.

## Главное сообщение

H1: «Пространство для вашей жизни».
Подзаголовок: «Продумываем интерьеры, в которых удобно жить: от первой планировки до последних деталей».
Главная кнопка: «Смотреть проекты» → /projects/.
Вторичная: «Обсудить интерьер» → /contact/.
Логотип — текстовый ПРОСТОР с аккуратным разрежением букв, без случайного значка.

## Главная по секциям

1. Header 88 px: логотип слева, Проекты / Подход / Контакты справа. На мобильном компактное меню.
2. Hero: заголовок на 7 колонок, небольшой текст на 3; под ними широкая фотография гостиной, подпись «Свет, воздух и естественные материалы». На мобильном заголовок, текст, кнопки, фото.
3. Избранные проекты: 3 асимметрично расположенные фотографии с названием, типом и площадью. Первая занимает 7 колонок, следующая 4 со смещением вниз; порядок чтения остаётся линейным.
4. Манифест: «Красивый интерьер начинается с того, как вы живёте». Две короткие колонки о планировке и материалах, небольшая детальная фотография.
5. Процесс: Знакомство → Планировка → Концепция → Документация. Четыре горизонтальных шага на desktop, вертикальный список на mobile.
6. Большой спокойный CTA «Начнём с вашего пространства» и ссылка на контакт.
7. Footer: навигация, подпись «Учебный концепт. Студия и проекты вымышлены».

## Шаблон кейса

Хлебные крошки → название и тип/площадь → широкая фотография → задача и решение в двух колонках → 2 дополнительные фотографии разного масштаба → палитра из 4 образцов с подписями материалов → следующий проект → CTA. Решение Astra от 08.09.2026: три изображения на кейс для быстрой первой версии. Стоковая подборка подписывается «Визуальное направление». Планировки включать только если подготовлены осмысленные схемы, а не декоративные псевдочертежи.

## Объём первой версии

Сначала главная и /projects/svet-i-dub/. Затем каталог, оставшиеся кейсы из тех же компонентов, /studio/ и /contact/. Не нужны личный кабинет, блог, калькулятор ремонта, CMS и сервер.

Текущая передача в реализацию: [IMPLEMENTATION_HANDOFF.md](IMPLEMENTATION_HANDOFF.md), этап 1 — Terra high, этап 2 — Terra low после контроля Astra. [Реальные веб-референсы и источники изображений](references/WEB_REFERENCES.md). Код приложения пока не создан.

## Что демонстрирует портфолио

Редакционная сетка, продуманная мобильная композиция, работа с фотографиями, единая система кейсов и доступный фильтр. Для адаптации под заказчика заменяются тексты и материалы, а структура остаётся пригодной для реальной студии.
