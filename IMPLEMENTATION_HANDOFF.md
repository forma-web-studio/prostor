## Что читать и кто решает

Прочитать `../README.md`, `README.md`, `ARCHITECTURE.md`, `VISUAL.md`, `references/WEB_REFERENCES.md`, затем этот файл. При расхождениях порядок этапов определяется здесь, технические детали — ARCHITECTURE, визуальные — VISUAL. CHAT_TASKS.md хранит прежний ручной процесс и не определяет текущий объём.

Astra отвечает за стек, структуру маршрутов и данных, арт-дирекцию и объём. Terra самостоятельно решает обычные детали вёрстки, исправляет ошибки и выбирает дополнительные лицензированные снимки по зафиксированному направлению. Смена стека, добавление сервиса/библиотеки, редизайн или расширение страниц — вынести в итог как вопрос для Astra; выполнять независимую согласованную часть. Не создавать отдельную задачу для согласования.

Общее решение: Astro + TypeScript strict + CSS, статическая сборка; Prata/Manrope, тёплый светлый фон, асимметричные избранные, простой каталог. Одна страница данных для четырёх концептов. Три изображения на кейс; честные подписи стока. Формы не отправляют данные. Публикация не входит в задание.
